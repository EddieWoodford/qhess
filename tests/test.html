Qhess regression tests

Replays every game in example_games/ through the real game page and checks that: the game replays without errors, the move history it writes back matches the file exactly, and the board state and what the page shows after every move match the snapshot recorded in tests/snapshots.json. It also has tests/generate.html replay a game by clicking through it the way a player does, and checks it plays the same game as before. Last, two copies of the game page play a game against each other through the server (multiplayer), one of them reloading part-way through. That needs the page to be served by the Qhess server (start_test.bat).
